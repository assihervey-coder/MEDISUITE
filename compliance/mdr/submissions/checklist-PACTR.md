# Checklist d'enregistrement — PACTR (Pan African Clinical Trial Registry)

> Enregistrement **public** de l'essai (ICTRP/OMS) — obligatoire **avant la
> 1ʳᵉ inclusion** (exigence ICMJE pour publication) ; visé M+3.
> Le jeu de données suit le **WHO Trial Registration Data Set** (24 items) ;
> les valeurs proviennent du protocole MEDISUITE-CI-01 — copier-coller
> tel quel dans le formulaire PACTR pour éviter toute divergence protocole↔registre.

## Procédure opérationnelle

1. Créer le compte promoteur sur le site PACTR ; vérifier les exigences
   courantes de pièces jointes (protocole, notice/consentement).
2. Saisir les 24 items à partir de ce document (source unique = protocole) ;
   tout écart constaté à la saisie → corriger le protocole (amendement) et
   non le registre.
3. À l'avis ANOC-CI : compléter l'item 21 et **enregistrer** → récupérer
   l'identifiant PACTR.
4. Reporter l'identifiant PACTR : index des soumissions, page de garde du
   protocole (amendement administratif), IFU si exigé, et future publication.
5. Mises à jour d'état (Recruiting → Completed) dans les 30 jours suivant le
   changement — calendrier tracé dans le registre des livrables R6-R9.
