# Limites du système

**Ce que TropiRAG EST** : une aide à la décision pour professionnels de santé,
couvrant le syndrome fébrile post-voyage en Afrique de l'Ouest, avec réponses
citées et auditables.

**Ce que TropiRAG N'EST PAS** :
- un dispositif de diagnostic autonome (interdit par conception et par garde)
- un prescripteur (aucune posologie n'est produite par le système)
- un substitut du jugement clinique ni de l'urgence vitale
- un système de dossiers médicaux complets

**Frontières d'exploitation** :
- Entrées : description clinique structurée ou texte libre FR
- Sorties : différentiel pondéré + conduite à tenir + preuves citées
- Mode dégradé : déterministe intégral sans GPU ni réseau
