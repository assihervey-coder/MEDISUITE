# Principes inaliénables

1. **IA ≠ autorité clinique** — le déterministe gouverne toujours.
2. **Pas de preuve, pas de synthèse** — refus constructif plutôt qu'invention.
3. **Zéro posologie par LLM** — l'extraction IA, la vérification déterministe.
4. **Diagnostic autonome interdit** — formulations verrouillées par guards.
5. **Cas critique = réponse 100 % déterministe** — la synthèse IA est suspendue.
6. **Traçabilité totale** — chaque réponse porte règles, preuves, modèles, versions.
7. **Déterminisme reproductible** — même cas, mêmes entrées → même sortie.
8. **Dégradation sûre** — pannes IA → repli heuristique, jamais de silence.
9. **Souveraineté des données** — tout local, aucune donnée vers des API externes.
10. **Le refus est une réponse** — attendue et documentée.
