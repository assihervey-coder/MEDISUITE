# Glossaire

- **Evidence Unit (EU)** : passage clinique autonome, sourcé, daté, citable — brique du RAG.
- **Evidence Pack** : ensemble d'EUs récupérées + rerankées pour une requête.
- **Red flag** : signe de gravité déclenchant urgence/escalade (déterministe).
- **Must-not-miss** : maladie dont l'omission est inacceptable → escalade si suspectée.
- **MVH/HCID** : maladie virale hémorragique / hautement contagieuse (Ebola, Marburg, Lassa).
- **CTA** : combinaison thérapeutique à base d'artémisinine (paludisme simple).
- **Safety Gate** : garde finale — 7 invariants (G1-G7) avant émission.
- **Model Mesh** : ensemble de modèles spécialisés derrière un routeur par capacité.
- **Capability Routing** : sélection du modèle PAR capacité requise, pas par prestige.
- **Mode déterministe** : fonctionnement intégral sans aucun modèle IA (repli garanti).
- **RRF** : Reciprocal Rank Fusion — fusion des rankings BM25 + vectoriel.
- **RSI** : Règlement Sanitaire International (notifications OMS).
