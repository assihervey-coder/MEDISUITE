# Scénario de référence — fièvre au retour de Côte d'Ivoire

Homme 34 ans, retour d'Abidjan (séjour rural, 9 j), fièvre 39,6 °C depuis
4 jours, frissons, vomissements importants, céphalées. Aucune biologie.

Sortie attendue (et testée) :
- Urgence : URGENCE (vomissements persistants = signe d'alarme dengue)
- Différentiel : 1. Paludisme (90 %) 2. Dengue (40 %)
- Examens : TDR + goutte épaisse + NFS + NS1/IgM
- Contre-indications : AINS (toutes molécules), CTA orale si vomissements
- Recommandé : paracétamol seul
- Citations : OMS paludisme + MSP-CI

Rejouer : `python scripts/run_case.py --scenario fever_travel_ci`
