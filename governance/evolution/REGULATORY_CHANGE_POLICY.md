# REGULATORY_CHANGE_POLICY

Classe plancher P9 si la proposition affecte : usage prévu, classification MDR,
sécurité/péformances revendiquées, documentation technique (TD-*), CER (MEDDEV 2.7/1),
soumissions ANOC/PACTR, UDI/EUDAMED.

Procédure : revue regulatory_affairs + clinical_lead + safety_officer (quorum comité),
mise à jour du dossier technique AVANT la release concernée, mise à jour GAP-ANALYSIS
et des checklists (`compliance/mdr/submissions/`).

Le pipeline eCRF → lock → SAF → SAP → CER (ADR-0026 / TD-11) n'est modifiable
que par P9 — ses artefacts sont la preuve réglementaire elle-même.
